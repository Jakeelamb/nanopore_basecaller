# Preserved continuation sources

`manifest.json` binds exact source snapshots to their original execution paths.
The snapshots preserve the dispatchers, typed Decision reuse, report boundary,
query0 prefix comparison, and retained-evidence auditors. Source manifests and
fixed case IDs are included. Raw sequencing data, runtime results, and admissions
are excluded.

The original SAMPLE source89 remains `63daa487...`. Its explicit census in
`tools/context_sample_feedback/boundary.py::sources()` excludes this directory.
The published snapshots do not change the qualified binary or original paths.
The typed continuation has its own source identity, receipts, and acceptance.
Its source-readiness packet records the exact two bounded commands. The initial
manifest and snapshots preserve the rejected terminal-key assumption. The
`superseding-v2/` manifest preserves the corrected genuine-terminal boundary and
separate measurement, compiled-emission and SAMPLE source roles.

`verify.py` checks every snapshot against the published hashes. Its `--live`
option also checks the original source locations and compiled source89. Both
modes read source bytes only and launch no scientific producer.

```sh
UV_PROJECT_ENVIRONMENT=/home/jake/Projects/nanopore_basecaller-retrieval/.venv UV_OFFLINE=1 UV_PYTHON_DOWNLOADS=never PYTHONDONTWRITEBYTECODE=1 uv run --no-sync python research/context-sample-feedback-provenance/verify.py --live --manifest research/context-sample-feedback-provenance/superseding-v2/manifest.json
```

These are exact archival copies, not alternate runtime entry points. Replay
restores the bytes at the original paths listed in the manifest. Execution still
requires the matching retained input receipts and a fresh bounded admission.
The source identity does not qualify biological accuracy or promotion.

`verify_counts.py --audit AUDIT` accepts one or more small retained measurement
audits. It independently computes exact rational error fractions and relative
reductions from integer match, substitution, insertion and deletion counts.
It rejects changed denominators, fractions, and 1% gate decisions. It reads no
SAM, trace, reference, or truth body and launches no scientific tool.
