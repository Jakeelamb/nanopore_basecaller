## Frozen inference

An original guarded decode runs once per case. Its six saved historical roles
and both old beams must match before outputs qualify. Free and original
population searches are reused from that decode. The sample and canonical
population-plus-sample union run new partial searches on copied windows. Paths
are unique before the 32-path cap. A path longer than 108 or an over-cap source
is named unavailable. There is no refill or frequency weighting. A missing
source contributes no paths to the combined union. A capped constituent makes
the combined source unavailable. Empty DNA is a valid deletion path.

U contains native and genuine finalists from successfully completed beams.
Free failure makes U native-only and stops all scored source arms at native.
Bounded or empty source beams do not contribute finalists and their source arm
abstains at native. Pruning alone is recorded. Each unique center receives full
`guarded_likelihood`, independently of its retained beam mass. NN(U) uses native
first and lexical ties. Every source arm scores the same U, filters at NN(U)
minus 0.5 neural log mass, and maximizes likelihood plus 0.5 potential. It accepts
only an improvement of at least 0.5 against the actual NN(U) contextual
objective. Output includes that baseline potential and objective.

`nn_u`, `historical_free`, `disabled_edits`, `population`, `sample`, `combined`,
`missing_source` and `wrong_source_control` remain distinct. The wrong-source
control takes the next distinct physical window in cyclic lexical case-ID
order. It is ranking-only, explicitly typed, and records the real source case.
It contributes no proposal origins. Source tables never directly add a DNA row
to U. NN(U) may edit. Only disabled edits require literal input SEQ/Q identity.
`proposal-diagnostics.tsv` separately records the original H neural maximum,
historical free and NN(U), their neural gain, and candidates absent old H.
The original H maximum is the maximum over old decoder candidates before its
historical abstention. It is diagnostic and cannot admit failed-beam finalists
to U. Source ranking effects are reported separately against frozen NN(U).

All full likelihoods are conditional on the original hard native4 initial
state, expanded interval, guards and copied whole-chunk model scores. The guide
and right guard use future information. Neither pruning nor this experiment
proves a global optimum, a signal likelihood ratio or a streaming decoder.

## Trace format and storage

Every enabled search stores every timestep, retained bundle and finalist.
`sample-guarded-exact-trace/1` begins with its ASCII schema and LF. Every integer
is little-endian u64. Every floating value is its exact IEEE754 u64 bit pattern.
The file stores pruning and bound booleans, step count, each step's timestep,
generated/merged/pruned counts, left-mass vector, retained bundle count, center
length and bytes, open mass, suffix vector, partial/terminal potential and rank.
The final list stores sequence length/bytes, state, retained signal mass,
potential and rank. All vectors carry a preceding u64 length.

After each successful native case, Python losslessly gzips each complete trace
with mtime zero. `trace-archives.json` binds the original size/hash and archive
pin. The adapter verifies decompressed bytes before removing its redundant raw
copy. Native completion pins continue to name those original bytes and are
validated through the explicit archive adapter. This representation does not
truncate a trace, beam, source, case or candidate.

Source-only size inspection found the three largest retained old two-beam
traces at 9,736,930, 11,855,649 and 13,014,758 bytes. That is an observation of
file sizes, not a new runtime or compression claim. New four-beam storage is
priced from each case's metadata before inference. Raw trace price must fit
half the 100 MiB new-output cap so compression has headroom. Genuine query0
must establish actual elapsed time, bytes, compression and memory before
remaining checkpoint or full-corpus intake. Cumulative output must remain under
4 GiB. A cap failure stays a failed attempt. It does not authorize omission.
